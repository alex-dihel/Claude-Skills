Color Scale Preview

Setup: 3-tier structure (Brand → Alias → Mapped). Brand roles: primary = emerald/500, secondary = violet/500. System roles: error = rose/500, warning = amber/500, success = lime/500, information = sky/500, neutral = slate/500.
Figma target: adds new Color/... and Opacity/... groups into the existing Brand collection (alongside Type/... and Scale/...); creates new Alias (single mode) and Mapped (Light/Dark modes) collections.
Updated since last preview: surfaces are now solid-fill only — the tinted surface concept has been replaced by a component-level Brand/Opacity utility scale (5-100%, illustrative only, not a persisted color token). Removing the tinted-surface contrast test also removed the two step-900 escalations from the previous preview (text-error and text-action-hover) — everything now resolves cleanly within the standard 6-step Alias scale, plus two explicitly-named structural extremes (Alias/neutral/extreme-light = slate-50, Alias/neutral/extreme-dark = slate-950) used for surface/page (light/dark mirror) and text/on-action.
  • Every Mapped token below references an Alias entry — no token needs to bind straight to Brand (no → Brand direct cases in this build).
  • disabled text/icon are shown as informational only — WCAG 1.4.3 exempts inactive UI components from contrast requirements.
  • surface/action and surface/primary both resolve to Alias/primary/default (same value, separate token names per the standard system-role-set rule).
